# First milestone UI

The initial app uses a single stateful player screen and a small custom-painted volume widget. Mock tracks drive title, search, and queue labels. The play button changes preview state only; the timer remains at zero because no playback engine is connected. The arc changes an in-app preview value, not operating-system audio volume. Hand preference is stored as a text value in the application support directory using `path_provider`.

The original design reference was supplied separately. Its cover photos are not copied because reuse rights were not provided; the screen uses a gradient placeholder. At this milestone, Telegram, local indexing, audio playback, and DLNA were not implemented.
